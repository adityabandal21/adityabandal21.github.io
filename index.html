Selected Projects

Four projects spanning generative AI, predictive modeling, synthetic data, and analytics.

RAG Document Q&A Chatbot

A retrieval-augmented chatbot that answers questions grounded in uploaded documents. Text is chunked and embedded, relevant passages are retrieved with FAISS, and answers are generated by Llama 3.3 70B served on Groq for low-latency inference.

LangChain FAISS Groq · Llama 3.3 70B Streamlit

Customer Churn Predictor

An XGBoost classifier that predicts which customers are likely to churn, reaching 0.84 AUC. SHAP value attributions explain each prediction, turning the model into a tool a business can actually act on rather than a black box.

XGBoost SHAP 0.84 AUC

Synthetic Data Generation

A comparison of three generative approaches — GAN, VAE, and CTGAN — for producing synthetic tabular data, evaluating each on data quality and downstream modeling utility using custom PyTorch implementations.

PyTorch GAN VAE CTGAN

Olist E-Commerce Analytics Dashboard

An interactive dashboard built on the Olist Brazilian e-commerce dataset, surfacing sales trends, delivery performance, and customer segments through a SQLite-backed data layer and Plotly visualizations.

SQLite Plotly Streamlit
